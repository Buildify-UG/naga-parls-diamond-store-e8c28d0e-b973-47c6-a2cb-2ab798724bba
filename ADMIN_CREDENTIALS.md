## 🎯 How It Works

### For Clients:
1. **Sign Up** - Create account with email and password
2. **Make Deposit** - Submit deposit via MTN or AIRTEL with transaction ID
3. **Wait for Approval** - Admin reviews and approves deposit
4. **Buy Plan** - Purchase diamond investment plan using wallet balance
5. **Earn Daily** - Receive daily profits automatically
6. **Refer & Earn** - Share referral link to earn commissions

### For Admin:
1. **Login** - Access admin panel with credentials
2. **Review Deposits** - Check pending deposits with transaction details
3. **Approve/Reject** - Approve deposits to add funds to user wallets
4. **Manage Products** - Edit product prices and daily profit rates
5. **Monitor System** - Track all transactions and user activity

## 💰 Referral Commission System

### How It Works:
- Share your unique referral link with others
- When they sign up and make purchases, you earn commissions
- **Level 1**: Direct referrals earn 28%
- **Level 2**: Your referrals' referrals earn 10%
- **Level 3**: Third-level referrals earn 3%

### Example:
- You refer John (Level 1) → John buys ₦50,000 plan
- You earn: ₦50,000 × 28% = **₦14,000**
- John refers Mary (Level 2) → Mary buys ₦30,000 plan
- You earn: ₦30,000 × 10% = **₦3,000**
