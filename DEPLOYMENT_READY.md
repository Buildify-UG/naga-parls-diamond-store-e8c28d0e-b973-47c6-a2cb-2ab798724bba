## 🚀 HOW TO USE

### Step 1: Login as Admin
1. Visit the website
2. Click "Login"
3. Enter: `admin@nagapearls.com` / `admin123`
4. You're in the admin dashboard

### Step 2: Manage Deposits
1. Click "Pending Deposits" tab
2. Review user deposits
3. Click "Approve" to add funds to their wallet
4. Or click "Reject" to decline

### Step 3: Manage Products
1. Click "Manage Products" tab
2. Edit product prices and daily profits
3. Changes apply instantly
4. Add new products as needed

### Step 4: Test as Client
1. Logout and login as: `client@nagapearls.com` / `client123`
2. Click "Make Deposit"
3. Select MTN or AIRTEL
4. Enter amount and transaction ID
5. Submit for approval
6. Wait for admin approval
7. Browse and buy plans
8. Earn daily profits
